# AI-Driven-Adaptive-Flow-Control-Dataset
Supporting data for an experimentally validated AI-driven adaptive flow control framework for Energy-Efficient Thermal Management of high-power electronic systems.
## Dataset Description

This repository contains the training dataset used for the experimentally validated AI-driven adaptive flow control framework for high-power electronic systems.

The dataset includes transient thermal measurements collected from an in-house microchannel heat-sink experimental platform.

Input parameters:
- Heat flux (q'')
- Coolant flow rate (Q)
- Inlet temperature (T_inlet)
- Previous maximum heat-sink temperature (T_max,prev)

Output parameter:
- Maximum heat-sink temperature (T_max)
